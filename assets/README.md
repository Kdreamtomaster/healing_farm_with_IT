# assets/ — 도트 그래픽

## 이 폴더는 왜 있나요? (기획안 10절)
게임의 모든 그림이 여기 있습니다. **도트 그래픽을 처음 그려 보는 사람도** 쉽게 고치고 추가할 수 있도록 구조를 최대한 단순하게 만들어요.

## 그래픽 원칙
- 모든 그림은 **도트(픽셀) 스타일로 통일**
- 과도한 디테일보다 **색채와 감성** 중심
- 편안한 색감, 계절 변화, 작은 애니메이션으로 힐링 분위기
- 정해진 팔레트(`palette.json`) 안의 색만 사용 → 누가 그려도 어울림

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 16×16 픽셀 PNG | 작고 단순한 크기라 무료 도트 편집기(예: Piskel, LibreSprite)로 바로 수정 가능 |
| 그림 1장 = 파일 1개 | 큰 그림 한 장(스프라이트 시트)보다 고칠 곳을 찾기 쉬움 |
| 파일 이름 규칙 | 이름만 보고 무슨 그림인지 알 수 있게 |
| `manifest.json` | 게임이 쓰는 그림 목록을 한 곳에 모음 |

## 폴더와 이름 규칙 (계획)
```
assets/
├── palette.json           ← 사용할 색 목록
├── manifest.json          ← 그림 목록
├── crops/                 ← tomato_1.png ~ tomato_4.png (성장 단계별)
├── tiles/                 ← soil.png, paddy_water.png, path.png
├── friends/               ← haneul_idle_1.png, haneul_idle_2.png
├── effects/               ← water_drop_1.png, locust_1.png
└── ui/                    ← 아이콘, 버튼 테두리
```
- 형식: `대상_상태_프레임.png` (모두 영어 소문자와 `_`)
- 애니메이션은 2~4프레임만 사용

## 그림 추가하는 법 (예정)
1. 16×16 캔버스에서 `palette.json`의 색으로 그리기
2. 이름 규칙에 맞춰 알맞은 폴더에 저장
3. `manifest.json`에 한 줄 추가

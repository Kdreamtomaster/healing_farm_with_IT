# server/lab/ — 연구소 세이브와 송장 (7단계)

## 이 폴더는 왜 있나요? (기획안 8절)
연구소(샌드박스)는 본 농장과 **다른 파일, 다른 키**를 써요. 이 폴더는 그 연구소 세이브를 다루고, 농장과 연구소 사이에 물건을 옮기는 일을 맡아요. 화면 쪽 설명은 [web/lab/README.md](../../web/lab/README.md)에 있어요.

## 파일
| 파일 | 하는 일 |
|---|---|
| `schema.sql` | 연구소 표: `samples`(실험 작물), `transfers`(송장), `integrity`(지문) |
| `store.py` | `LabStore`: `saves/lab.sqlite` 와 연구소 전용 키 `saves/.lab-key`. 불러오기(지문 실험대 재료 포함), 실험(색·크기), 받기, 연료 보내기, 비우기 |
| `transfer.py` | 농장 ↔ 연구소 옮기기와, 중간에 끊긴 옮기기 이어 하기(`recover`) |

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 파일 단위 격리 | 연구소에서 무엇을 해도 `farm.sqlite` 와 농장 키에는 닿지 않아요 (샌드박스) |
| 허용 목록 | 연구소 → 농장으로는 `biofuel` 하나만. 연구소 작물은 선물·요리에 못 써요 |
| 송장 번호 (멱등 처리) | 두 파일에 걸친 옮기기를 한 트랜잭션으로 묶을 수 없어서, 받는 쪽은 처음 보는 송장만 처리. 중간에 꺼져도 두 번 더해지지 않아요 |
| 지문이 맞지 않는 쪽의 기록은 믿지 않기 | 연구소 세이브를 고쳐 "보내는 중" 송장을 지어내도 연료가 생기지 않아요 |

## 옮기는 순서
```
농장 → 연구소 (작물):  ① 농장: 작물 빼기 + 송장 기록 (+ 새 지문)   ② 연구소: 처음 보는 송장이면 받기
연구소 → 농장 (연료):  ① 연구소: 실험 작물 빼기 + "보내는 중" 송장
                      ② 농장: 처음 보는 송장이면 biofuel 더하기   ③ 연구소: 송장 "도착"
서버를 켤 때: recover() 가 끊긴 ②·③ 을 이어서 해요
```
서버가 농장 세이브의 창고를 바꾸면, 브라우저도 같은 만큼 자기 창고를 바꿔요(`web/lab/sandbox.js`). 그래서 다음 저장 때 둘이 어긋나지 않아요.

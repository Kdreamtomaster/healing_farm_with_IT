# 03. 시간 처리와 방치형 진행

**한 줄 요약** — 게임을 꺼 둔 시간은 "마지막 저장 시각"과 "다시 켠 시각"의 차이로 계산하고, 그 시간을 잘게 나눠 다시 흘려보낸다.

## 쉬운 비유
여행을 다녀오면 "3일 동안 비웠으니 화분 물이 말랐겠다"고 생각하죠. 게임도 **떠난 시각만 기억해 두면**, 돌아왔을 때 무슨 일이 있었을지 계산할 수 있어요.

## 핵심 개념
- **타임스탬프** — 특정 순간을 숫자로 적은 것 (1970년 1월 1일부터 몇 밀리초가 지났는지)
- **경과 시간** — `다시 켠 시각 - 마지막 저장 시각`
- **조각 시뮬레이션** — 긴 시간을 한 번에 계산하지 않고 잘게 잘라 반복 → 중간에 흙이 마르는 순간도 놓치지 않음
- **경계 조건** — 이상한 값 대비: 시계를 뒤로 돌려 음수가 되거나, 1년 만에 접속해 너무 클 때
- **시간 배율** — 게임 속 시계는 현실보다 빠르게 흐를 수 있음. `게임 시간 = 현실 시간 × 배율`
- **결정적(늘 같은) 무작위** — 날짜와 씨앗 값으로 계산하는 "의사 난수"라서, 같은 날은 언제 다시 계산해도 같은 결과
- **저장 시점 설계** — 언제 저장할지 정하는 것도 설계. 너무 자주 하면 느리고, 드물면 많이 잃음

## 게임 속에서는
| 하는 일 | 코드 |
|---|---|
| 현실 시간 → 게임 시간 (`ms ÷ 60000 × 배율`) | `web/time/clock.js` 의 `realMsToGameMinutes` |
| 비운 시간 계획: 최대 5일로 자르기, 시계가 거꾸로 갔는지 확인 | `web/time/offline.js` 의 `planOffline`, `OFFLINE_CAP_MS` |
| 게임 시간 10분 조각마다 성장 + 친구들의 물주기·수확 | `web/time/offline.js` 의 `simulateOffline`, `web/time/helpers.js` |
| 돌아왔을 때 안내 화면 | `web/time/summary.js` 의 `summarize`, `web/main.js` 의 `catchUp` |
| 5분마다 / 탭을 숨기거나 창을 닫을 때 저장 | `web/time/autosave.js` 의 `startAutosave` |
| 실행 시각 기록 | `server/storage/store.py` 의 `open` (`lastLaunchAt`) |
| 날씨: 날짜와 농장 씨앗으로 정해짐 | `web/farm/weather.js` 의 `weatherOfDay` |

**같은 코드로 두 번 쓰기** — 성장 계산 `advanceCrop(작물, 품종, 칸 종류, 흐른 분, 날씨)`는 "지금 시각"을 스스로 읽지 않고 **흐른 시간을 인자로 받아요**. 그래서 플레이 중 1초마다(`tick`) 계산할 때와, 비운 5일을 한꺼번에 계산할 때가 **똑같은 함수**예요. 날씨도 늘 같은 무작위라서 "그날 비가 왔는지"를 나중에 계산해도 정확해요.

## 실제 제품에서는
- 모바일 방치형 게임의 오프라인 보상
- 구독 서비스의 "남은 기간", 배달 앱의 "도착 예정 시각"
- 서버들끼리 시계가 조금씩 달라서 생기는 문제(시계 어긋남)를 다루는 것도 중요한 엔지니어링 주제예요. 이 게임도 그래서 시각을 **서버**가 알려 줘요 (`/api/state` 의 `serverNow`)

## 직접 해 보기
1. 🌱 게임을 켜 둔 채 다른 탭에서 몇 분 놀다 돌아오기 → 안내 화면에 비운 시간과 친구들이 한 일이 나와요
2. 🌿 경계 조건 실험: 게임 화면에서 `F12` → Console 탭에 붙여 넣기
   ```js
   const t = await import("/web/time/offline.js");
   t.planOffline(0, -3600000, 30);           // 시계가 1시간 거꾸로 → clockWentBack: true, 0분 처리
   t.planOffline(0, 0, 30);                  // 0초 → 아무 일도 없음
   t.planOffline(0, 30 * 86400000, 30);      // 30일 → capped: true, 5일치만 계산
   ```
3. 🌱 설정 탭(`O`)에서 시간 배율을 ×1 ↔ ×60 으로 바꿔 보고 작물이 자라는 속도와 하늘 색이 바뀌는 속도 비교하기
4. 🌿 늘 같은 무작위 확인: Console 에서 농장 씨앗 42 의 첫 7일 날씨를 두 번, 씨앗 100 으로 한 번
   ```js
   const w = await import("/web/farm/weather.js");
   const week = (seed) => Array.from({ length: 7 }, (_, day) => w.weatherOfDay(day, seed).kind).join(" ");
   [week(42), week(42), week(100)];
   ```
   같은 씨앗은 몇 번을 계산해도 같은 날씨, 씨앗이 다르면 다른 날씨예요

# 04. 데이터 파이프라인과 라벨링

**한 줄 요약** — 흩어진 기록을 모으고, 다듬고, 이름표를 붙여야 쓸모 있는 정보가 된다.

## 쉬운 비유
수확한 채소를 그대로 쌓아 두면 쓰기 어려워요. **씻고(정리) → 종류별로 나누고(분류) → 이름표를 붙이고(라벨링) → 상자에 담아야(저장)** 요리에 바로 쓸 수 있죠. 데이터도 같은 과정을 거칩니다.

## 핵심 개념
- **원본 데이터(raw)** — 가공 전 기록. 예: "게임 시각 600분, 하늘이가 3번 칸에 물을 줌"
- **파이프라인** — 데이터가 여러 단계를 차례로 지나며 가공되는 흐름 (수집 → 정리 → 집계 → 활용)
- **스키마 일관성** — 같은 칸에는 같은 뜻·같은 모양의 값이 들어가야 함. 어긋나면 "정리" 단계가 고생해요
- **집계** — 여러 기록을 합쳐 요약. 예: "친구별로 도와준 횟수"
- **라벨링** — 데이터에 뜻을 알려 주는 이름표 달기. 인공지능이 배우는 데이터도 사람이 라벨을 붙여 만듦
- **라벨 품질** — 이름표가 틀리면 그 데이터로 내린 판단도 틀림

## 게임 속에서는
**수집** — 모든 일이 `task_log` 표에 한 줄씩 쌓여요 (`web/main.js` 의 `record` → 저장할 때 `server/storage/db.py` 의 `append_log`)

| 열 | 뜻 | 예 |
|---|---|---|
| `at` | 게임 시각(분) | `1863.5` |
| `actor` | 누가 | `player`, `하늘`, `멍때리기`, `system` |
| `action` | 무엇을 | `plant`, `water`, `harvest`, `cook`, `share`, `craft`, `gift` … |
| `detail` | 자세히 | `3`, `tomato:3`, `tulip_bouquet:bomi` |

**라벨이 일하는 곳** — `data/crops.json` 의 `type`(밭/논/꽃)과 `water`(low/mid/high)는 이름표예요.
- `type` → 어느 칸에 심을 수 있는지 (`web/farm/crops.js` 의 `PLOT_FOR_TYPE`)
- `water: "high"` → 스프링클러가 물을 줄 작물 (`web/farm/care.js` 의 `BULK.highWater`)

**정리가 필요한 진짜 사례** — 이 게임의 기록에도 "정리" 단계가 필요한 곳이 있어요. 일부러 남겨 둔 실제 모습이에요.
| 문제 | 예 | 왜 곤란할까? |
|---|---|---|
| 같은 `action` 인데 `detail` 뜻이 다름 | 플레이어 `water` 는 칸 번호 `3`, 친구 `water` 는 물 준 칸 수 `5` | "몇 번 물 줬나?"를 셀 때 섞이면 틀려요 |
| 같은 열에 이름과 id 가 섞임 | `actor` 에 `player`(id)와 `하늘`(화면 이름) | 친구 이름을 바꾸면 옛 기록과 이어지지 않아요 |
| 이름표 하나가 두 가지 뜻 | 친구에게 준 선물과 새 씨앗 선물이 둘 다 `gift` | 선물 통계가 부풀어요 |
| `plant` 기록에 작물 이름이 없음 | `detail` 이 칸 번호 `3` 뿐 | "가장 많이 심은 작물"을 셀 수 없어요 |

🚧 **6단계에서 만들 것** ([PLAN.md](../PLAN.md) 6단계)
- 기록 모양 정리(새 기록부터 `detail` 을 JSON 으로, `actor` 는 id 로) + 옛 기록을 고쳐 읽는 "정리" 단계
- **농장 일지** 화면: ① 원본 기록 → ② 정리 → ③ 집계 표 → ④ 해금 진행 막대를, 각 표를 만든 **SQL 문장과 함께** 보여 주기
- **도감**: 드물게 나오는 돌연변이 작물을 보고 특징 이름표(색·모양·크기)를 달고 이름 붙이기. 게임은 정답을 알고 있어서 "라벨이 맞았는지"를 부드럽게 알려 줘요

## 실제 제품에서는
- 쇼핑 앱이 "이 상품을 본 사람이 산 상품"을 추천하려면 클릭 기록 파이프라인이 필요해요. 회사에서 데이터 일을 하는 사람들은 **정리 단계에 가장 많은 시간**을 쓴다고들 해요
- 자율주행 AI를 위해 사람들이 사진 속 사람·자동차·신호등에 라벨을 붙여요. 같은 사진을 여러 사람이 라벨링해 서로 맞는지 비교하기도 해요(라벨 품질 검사)


   ```bash
   python tools/sql.py "SELECT actor, action, detail FROM task_log WHERE action = 'water' LIMIT 10"
   ```

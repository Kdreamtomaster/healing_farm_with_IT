# saves/ — 내 세이브 파일

## 이 폴더는 왜 있나요?
게임을 실행하면 여기에 **나만의 농장 기록**이 만들어집니다. 사람마다 내용이 다르기 때문에 Git에는 올리지 않아요 (`.gitignore`로 제외).

## 생기는 파일 (예정)
| 파일 | 내용 |
|---|---|
| `farm.sqlite` | 본 농장 세이브 (SQLite 데이터베이스) |
| `lab.sqlite` | 연구소 전용 세이브 — 본 농장과 분리된 샌드박스 |
| `backups/` | 최근 정상 저장본 몇 개 (복구용) |
| `.key` | 무결성 확인용 비밀 키 (처음 실행 시 자동 생성) |

## 알아 두면 좋은 것
- 위치는 항상 **프로젝트 폴더 기준 상대 경로**입니다. 프로젝트 폴더를 통째로 옮기면 세이브도 함께 옮겨져요.
- 폴더 이름에 한글이 있어도 괜찮아요 (예: `D:\내 게임\힐링농장\saves\`).
- `farm.sqlite`를 직접 고치면 다음 실행 때 무결성 이상(메뚜기 떼!)이 나타날 수 있어요. 실험은 연구소에서 해 보세요.
- 처음부터 다시 하고 싶다면 게임을 끈 뒤 이 폴더의 파일을 지우면 됩니다 (이 README는 남겨 두세요).

# tests/ — 규칙이 맞게 동작하는지 확인하기

## 이 폴더는 왜 있나요?
"토마토는 2시간 뒤에 다 자란다", "시계를 뒤로 돌려도 게임이 깨지지 않는다" 같은 약속을 **코드로 자동 확인**하는 곳입니다. 코드를 고친 뒤 테스트를 돌리면 다른 기능이 망가지지 않았는지 바로 알 수 있어요.

## 어떤 기술을 쓰나요?
| 대상 | 기술 | 의도 |
|---|---|---|
| 서버 (`server/`) | Python `unittest` (표준 라이브러리) | 설치 없이 `python -m unittest` 로 실행 |
| 게임 규칙 (`web/`) | 브라우저에서 여는 테스트 페이지 `tests/web/index.html` | Node.js 같은 추가 설치 없이 Chrome만으로 확인 |

## 꼭 확인할 것 (초안)
- **저장/복구**: 저장 → 불러오기 결과가 같은가, 저장 도중 실패하면 이전 상태가 유지되는가
- **경로**: 한글·공백이 있는 폴더에서 세이브가 만들어지는가
- **시간**: 경과 시간 0, 음수, 5일 초과(30일)일 때 안전하게 처리되는가 (5일로 잘림)
- **배율**: 배율 1배와 12배에서 게임 시간·성장이 배율만큼 차이 나는가
- **친구 관리**: 오프라인 동안 다 자란 작물이 수확되어 창고에 들어가는가
- **무결성**: 한 글자만 바꿔도 해시 검증이 실패하고 초기화되는가
- **손상 vs 변조**: 깨진 파일은 초기화가 아니라 백업 복구로 처리되는가
- **연구소**: 연구소 작물이 선물 재료로 쓰이지 않는가
- **DAG**: 순환 연결을 거부하는가, 실패한 작업이 정해진 횟수만큼 재시도되는가

## 실행하기
```bash
# 서버 테스트 (프로젝트 폴더에서)
python -m unittest discover -s tests/server -t tests/server
```
게임 규칙 테스트는 `python server/main.py` 로 서버를 켠 뒤 Chrome에서 `http://127.0.0.1:8765/tests/web/` 를 엽니다.

## 파일
| 파일 | 확인하는 것 |
|---|---|
| `server/test_storage.py` | 한글 경로 새 농장, 저장 후 재실행 복원, 구획 배치 변경 거부, 깨진 파일 백업 복구, 백업 5개 유지 |
| `server/test_integrity.py` | 지문 계산, 세이브 직접 수정 감지와 저장 잠금, 키 삭제 감지 |
| `server/test_migrations.py` | 옛 버전 세이브 옮기기(1→2→3, 시든 작물 되살리기), 변조된 옛 세이브는 계속 변조, 더 새 버전 거부 |
| `server/test_api.py` | 경로 조작 차단, 입력 검증, 다른 웹사이트 요청 차단, 저장 왕복 |
| `web/farm.test.js` | 성장, 수분, 다 자란 작물은 계속 기다림, 심기, 수확, 일괄 관리 |
| `web/decor.test.js` | 계절 달력, 테두리 색, 작물 색 고르기 |
| `web/sound.test.js` | 음 이름 → 진동수, 효과음·배경음이 실제로 소리를 내는지 (스피커 없이 미리 만들어 확인) |
| `web/time.test.js` | 비운 시간 0·음수·5일 초과, 배율, 친구들의 물주기·수확, 나눠 처리해도 같은 결과, 안내 문장 |
| `web/animations.test.js` | 농부·친구·드론·스프링클러·물길이 칸마다 한 번씩 일하는지, 순서, 1초 안 도착, 일손 최대 4명, 친구가 돌아가는지 |
| `web/layout.test.js` | 가로·세로 화면 배치, 창고가 화면 안에 들어가는지, 정수 확대 배율 |
| `web/autopilot.test.js` | 멍때리기 모드의 일 순서, 무작위 색, 가는 중인 칸 건너뛰기 |
| `web/cooking.test.js` | 요리 재료 소비·모자란 재료·끓는 동안 재료 중복 방지·나눠 먹기 |
| `web/index.html`, `web/runner.js` | 브라우저용 작은 테스트 도구 |

서버 테스트는 실제 `saves/` 대신 임시 폴더(`…/내 게임/힐링 농장/`)를 써서 내 세이브를 건드리지 않아요.

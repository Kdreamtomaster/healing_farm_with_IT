# tests/ — 규칙이 맞게 동작하는지 확인하기

## 이 폴더는 왜 있나요?
"토마토는 2시간 뒤에 다 자란다", "시계를 뒤로 돌려도 게임이 깨지지 않는다" 같은 약속을 **코드로 자동 확인**하는 곳입니다. 코드를 고친 뒤 테스트를 돌리면 다른 기능이 망가지지 않았는지 바로 알 수 있어요.

## 어떤 기술을 쓰나요?
| 대상 | 기술 | 의도 |
|---|---|---|
| 서버 (`server/`) | Python `unittest` (표준 라이브러리) | 설치 없이 `python -m unittest` 로 실행 |
| 게임 규칙 (`web/`) | 브라우저에서 여는 테스트 페이지 `tests/web/index.html` | Node.js 같은 추가 설치 없이 Chrome만으로 확인 |

## 꼭 확인할 것 (초안)
- **저장/복구**: 저장 → 불러오기 결과가 같은가, 저장 도중 실패하면 이전 상태가 유지되는가
- **경로**: 한글·공백이 있는 폴더에서 세이브가 만들어지는가
- **시간**: 경과 시간 0, 음수, 5일 초과(30일)일 때 안전하게 처리되는가 (5일로 잘림)
- **배율**: 배율 1배와 12배에서 게임 시간·성장이 배율만큼 차이 나는가
- **친구 관리**: 오프라인 동안 다 자란 작물이 수확되어 창고에 들어가는가
- **무결성**: 한 글자만 바꿔도 해시 검증이 실패하고 초기화되는가
- **손상 vs 변조**: 깨진 파일은 초기화가 아니라 백업 복구로 처리되는가
- **연구소**: 연구소 작물이 선물 재료로 쓰이지 않는가
- **DAG**: 순환 연결을 거부하는가, 실패한 작업이 정해진 횟수만큼 재시도되는가

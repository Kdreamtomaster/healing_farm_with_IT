# web/friends/ — 농부의 친구와 나눔

## 이 폴더는 왜 있나요? (기획안 5절)
수확의 기쁨을 **나누는 기쁨**으로 이어 주는 곳입니다. 수확물을 "토마토 10개"처럼 숫자로 건네는 대신, 정성 들여 만든 **선물**로 표현해요.

## 담당 기능
### 1. 선물 만들기
| 재료 | 선물 예시 |
|---|---|
| 꽃 | 화분, 꽃다발 |
| 농작물 | 손질한 재료(씻은 감자, 말린 고추), 음식(토마토 수프, 주먹밥) |

- 선물 레시피는 `data/gifts.json`에 정리
- 같은 레시피라도 **무작위로 품질 등급**이 나뉨 (평범한 / 정성스러운 / 특별한)

### 2. 친구별 반응
- 친구마다 좋아하는 색, 재료, 선물 종류가 다름 (`data/friends.json`)
- 선물 × 친구 조합 + 약간의 무작위 → 반응 대사와 친밀도 변화
- 오프라인 동안 농장을 돌봐 준 친구에게 고마움을 전하는 흐름과 연결

### 3. 숨은 성장 요소
- 나눔을 할 때마다 화면에 보이지 않는 **나눔 경험치**가 쌓임
- 경험치가 높을수록 "특별한" 등급 선물이 나올 확률이 조금씩 올라감
- 일부러 숫자로 보여 주지 않아 "요즘 선물이 더 근사해졌네?" 하는 발견의 재미를 줌

### 4. 나눌 수 없는 것
- 연구소(`lab/`)에서 실험한 작물은 선물 재료로 쓸 수 없음 → 바이오 연료로만 전환

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 가중치 무작위 선택 | 등급별 확률을 표로 두고, 경험치에 따라 가중치를 조정 |
| 규칙 표(조합 → 반응) | 대사와 반응을 코드가 아닌 데이터로 관리해 누구나 친구 대사를 추가 가능 |
| 출처 태그 (`origin: farm / lab`) | 연구소 작물이 선물로 새어 나가지 않도록 재료 출처를 검사 |

## 들어올 파일 (예정)
- `crafting.js` — 선물 만들기와 등급 판정
- `reactions.js` — 친구 반응과 친밀도
- `sharing.js` — 나눔 경험치 관리

# web/sound/ — 도트 감성 소리

## 이 폴더는 왜 있나요?
도트 그래픽과 어울리는 **옛 게임기 느낌(칩튠)의 잔잔한 소리**로 힐링 분위기를 더합니다. 소리 파일을 쓰지 않고, 브라우저에 들어 있는 **Web Audio API로 소리를 직접 만들어요.**

## 담당 기능
| 소리 | 언제 |
|---|---|
| 효과음 `plant` | 씨앗을 심을 때 — 낮은 음에서 "뽁" |
| 효과음 `water` | 물주기·논 물대기·일괄 물주기 — 미끄러져 내려오는 물방울 |
| 효과음 `drone`, `drip` | 드론이 떠오를 때 "위잉", 칸에 뿌릴 때 물방울 한 방울 |
| 효과음 `sprinkler` | 스프링클러가 돌 때 "칙칙칙" |
| 효과음 `flow` | 논에 물이 흘러들 때 "졸졸" |
| 효과음 `harvest` | 수확할 때 — 도·미·솔·도 |
| 효과음 `save` | 저장 버튼을 눌렀을 때 — 딩동 (자동 저장은 조용히) |
| 효과음 `welcome` | 비운 시간 안내가 나올 때 — 짧은 인사 멜로디 |
| 배경음 | 짧은 음을 천천히 반복하는 잔잔한 곡 |

- 설정에서 효과음·배경음을 켜고 끄고 음량을 조절 (기본: **효과음만 켜짐**)
- 소리 설정은 게임 진행이 아니라 "이 컴퓨터에서의 취향"이라 세이브 대신 브라우저(localStorage)에 보관
- 탭을 숨기면 배경음도 쉼

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| Web Audio API `OscillatorNode` | 네모파(square)·세모파(triangle)로 옛 게임기 소리를 직접 만듦. 파일이 없어 라이선스 걱정이 없음 |
| 음 이름 → 진동수 공식 | `"A4"` = 440Hz, 한 옥타브 위는 두 배. 악보를 숫자 대신 음 이름으로 쓸 수 있음 |
| 소리 크기 곡선(envelope) | "톡" 하고 시작해 부드럽게 사라지게 → 귀가 편안함 |
| 고음 깎기 필터(lowpass) | 네모파의 날카로움을 줄여 힐링 분위기에 맞춤 |
| 5음계(도 레 미 솔 라) 무작위 멜로디 | 어떤 순서로 골라도 서로 잘 어울려서, 매번 조금씩 다른데도 듣기 편한 배경음 |
| 미리 예약하기(lookahead) | `setInterval`은 정확하지 않아서, 0.6초 앞의 음을 오디오 시계에 미리 예약 |

### 브라우저 규칙
브라우저는 사용자가 화면을 한 번 누르기 전에는 소리를 내지 못하게 막아 둡니다. 그래서 첫 클릭 때 소리 장치를 준비하고, 접속하자마자 뜨는 안내 화면의 인사는 "농장으로" 버튼을 누를 때 들려줘요.

## 파일
| 파일 | 하는 일 |
|---|---|
| `notes.js` | 음 이름 → 진동수, 음 하나 내기 |
| `effects.js` | 효과음 악보 — **여기 숫자만 바꿔도 소리가 바뀌어요** |
| `music.js` | 배경음 만들기 |
| `engine.js` | 켜고 끄기, 음량, 소리 장치 준비 |

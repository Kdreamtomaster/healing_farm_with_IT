# web/decor/ — 색과 배치로 꾸미기

## 이 폴더는 왜 있나요? (기획안 3, 10절)
이 게임의 꾸미기는 의자나 분수 같은 장식을 늘어놓는 방식이 아니에요. **구획의 색 조합, 꽃과 작물의 색, 계절감**만으로 나만의 농장을 완성합니다. 복잡한 장식 대신 색과 배치에 집중해 도트 그래픽과도 잘 어울리고, 리소스도 단순하게 유지할 수 있어요.

## 담당 기능
- **구획별 색 조합** — 구획마다 흙/테두리/길 색을 팔레트에서 골라 설정
- **작물 색 활용** — 같은 튤립이라도 빨강·노랑·보라 품종을 심어 무늬 만들기 (색은 `farm/`의 품종 데이터에서 옴)
- **계절감** — 봄/여름/가을/겨울에 따라 배경, 빛 색조, 작은 애니메이션(꽃잎, 낙엽, 눈) 변화
- **미리보기** — 심기 전에 "이 자리에 노란 꽃을 심으면 어떻게 보일지" 미리 보기

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 팔레트 기반 색 관리 (`assets/palette.json`) | 정해진 따뜻한 색 묶음 안에서 고르게 하여 어떤 조합도 편안해 보이게 함 |
| 팔레트 스왑 | 그림 한 장의 색만 바꿔 여러 품종·계절을 표현 → 도트 파일 수를 줄임 |
| CSS 변수 / 캔버스 색조 필터 | 계절에 따라 화면 전체 분위기를 한 번에 바꿈 |

# web/decor/ — 색과 배치로 꾸미기

## 이 폴더는 왜 있나요? (기획안 3, 10절)
이 게임의 꾸미기는 의자나 분수 같은 장식을 늘어놓는 방식이 아니에요. **구획의 색 조합, 꽃과 작물의 색, 계절감**만으로 나만의 농장을 완성합니다. 복잡한 장식 대신 색과 배치에 집중해 도트 그래픽과도 잘 어울리고, 리소스도 단순하게 유지할 수 있어요.

## 담당 기능
- **구획별 테두리 색** — 칸을 고르고 팔레트에서 테두리 색 선택. "밭 칸 모두 이 색으로"로 같은 종류 칸을 한 번에
- **작물 색 고르기** — 같은 튤립이라도 분홍·노랑·보라·하양을 골라 심어 무늬 만들기 (색 목록은 `data/crops.json`)
- **미리보기** — 빈 칸에서 색 버튼에 마우스를 올리면 다 자랐을 때 모습이 반투명하게 보임
- **계절감** — 게임 속 날짜로 봄·여름·가을·겨울이 바뀌고, 계절마다
  - 화면 색조와 바탕색이 살짝 바뀜
  - 작은 입자 애니메이션: 봄 꽃잎, 여름 반딧불, 가을 낙엽, 겨울 눈

## 게임 속 달력
- 한 계절 = 게임 속 7일, 한 해 = 28일
- 상태 줄에 "1년차 봄 3일째 07:30"처럼 표시
- 기본 배율 ×30 에서 한 계절은 현실 약 5시간 36분
- 계절은 아직 보이는 것만 바꿉니다 (작물 성장에는 영향 없음)

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 팔레트 기반 색 관리 (`assets/palette.json`) | 정해진 따뜻한 색 묶음 안에서 고르게 하여 어떤 조합도 편안해 보이게 함 |
| 팔레트 스왑 (`ui/sprites.js`) | 그림 한 장의 표시색만 바꿔 여러 색의 작물을 표현 → 도트 파일 수를 줄임 |
| 반투명 색조 덮기 + 입자 | 그림 파일을 계절마다 따로 그리지 않고도 계절 분위기를 냄 |
| 색 id 로 저장 | 저장에는 `"pink"` 같은 이름표만 남기고 실제 색은 데이터에서 찾음 → 색을 다듬어도 세이브는 그대로 |

## 파일
| 파일 | 하는 일 |
|---|---|
| `palette.js` | 테두리·작물 색 찾기, 색 섞기 |
| `plots-style.js` | 테두리 색 바꾸기, 같은 종류 칸 모두 바꾸기 |
| `season.js` | 게임 날짜 → 계절, 달력 표시 |

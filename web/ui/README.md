# web/ui/ — 화면 그리기

## 이 폴더는 왜 있나요? (기획안 4, 10절)
게임 규칙이 계산한 결과를 **도트 그래픽 화면**으로 보여 주고, 플레이어의 클릭을 받아 규칙에 전달하는 곳입니다. 규칙(`farm/` 등)과 그리기(`ui/`)를 나눠 두면, 그림을 바꿔도 규칙이 깨지지 않고 규칙을 바꿔도 그림을 다시 그릴 필요가 없어요.

## 담당 기능
- **농장 화면** — 타일 격자 위에 구획, 작물, 친구 캐릭터 그리기
- **작은 애니메이션** — 흔들리는 새싹, 물방울, 꽃잎 (2~4프레임의 단순한 반복)
- **로딩 화면** — 재접속 시 경과 시간 안내 멘트와 오프라인 처리 진행 표시 (`time/`의 요약 사용)
- **알림** — 무결성 이상 배지, 저장 실패/복구 안내, 돌연변이 발견 축하
- **패널** — 도감, 선물 만들기, 스마트팜 편집기, 연구소 화면의 틀

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| `<canvas>` 2D + 정수 배율 확대 | 16×16 도트를 2배·3배로 또렷하게 확대 |
| `requestAnimationFrame` | 화면이 보일 때만 부드럽게 그리기, 탭이 숨겨지면 자동으로 쉼 |
| HTML 버튼/패널 + CSS | 글자와 버튼은 캔버스 대신 HTML로 → 한글 표시와 접근성이 쉬움 |
| 리소스 목록 (`assets/manifest.json`) | 그림 파일 이름을 한 곳에 모아 그림 추가가 쉬움 |

## 파일
| 파일 | 하는 일 | 상태 |
|---|---|---|
| `renderer.js` | 캔버스 그리기: 흙·테두리, 작물 그림, 흔들림, 계절 색조와 입자, 미리보기, 물주기 연출 (1초에 24번) | ✔ |
| `panels.js` | 선택한 칸, 일괄 관리, 창고, 상태 줄 | ✔ |
| `toast.js` | 짧은 알림 | ✔ |
| `dom.js` | 화면 요소를 안전하게 만드는 도우미 (innerHTML 대신 사용) | ✔ |
| `sprites.js` | 그림 파일 불러오기, 팔레트 스왑(작물 색으로 바꿔 칠하기) | ✔ |
| `loading.js` | 재접속 로딩 화면: 진행 막대, 비운 동안의 안내 | ✔ |
| `layout.js` | 화면 배치: 가로(16:9)는 창고 마당을 밭 오른쪽에, 세로(9:16·갤럭시 S25)는 밭 아래에. 정수 배율 확대 | ✔ |
| `scenery.js` | 농장 배경(풀밭·길·울타리·나무·헛간)과 창고 풍경(쌓이는 수확물 상자, 늘어나는 씨앗 자루) | ✔ |
| `animations.js` | 농사 연출: 걸어가서 일하는 농부와 도우러 오는 친구들, 드론, 스프링클러, 논 물길 | ✔ |

## 배경과 창고 풍경
- 밭 둘레에 풀밭, 울타리, 나무, 흙길, 헛간. **풀과 나뭇잎 색은 계절마다** (봄 꽃나무, 여름 초록, 가을 단풍, 겨울 눈)
- 헛간 앞 마당에 작물마다 **수확물 상자**: 창고에 그 작물이 많을수록 상자 위에 피라미드처럼 쌓임 (최대 10개까지 보임)
- 그 아래 **씨앗 자루**: 씨앗 3개마다 한 자루씩, 최대 3자루. 자루 띠는 작물 색

## 반응형 화면
| 화면 | 배치 |
|---|---|
| 가로로 넓은 화면 (16:9 PC, 폭 1000px 이상) | 농장 옆에 메뉴 |
| 좁은 가로 화면 (갤럭시 S25 가로 등) | 농장 아래에 메뉴 (카드 여러 줄) |
| 세로 화면 (9:16, 갤럭시 S25 세로) | 농장 아래에 메뉴, 창고 마당도 밭 아래로 |

- 도트가 고르게 보이도록 확대는 정수 배(×2, ×3 …)로, 화면이 아주 작을 때만 소수 배
- 손가락으로 누르는 기기에서는 버튼을 크게, 두 번 톡 쳐서 확대되는 것은 막음

## 농사 연출
| 행동 | 연출 |
|---|---|
| 심기 / 물주기 / 논에 물대기 / 수확 (한 칸) | 농부가 걸어가서 일함 (아무리 멀어도 1초 안에 도착). 심을 땐 흙이 톡톡, 수확할 땐 반짝 |
| 요리하기 | 농부가 화덕 앞에서 보글보글 (김이 모락모락), 다 되면 창고에 요리 |
| 나눠 먹기 | 농부와 친구 셋이 피크닉 돗자리에 둘러앉아 냠냠, 하트가 퐁퐁. 다 먹으면 친구들은 돌아감 |
| 빠르게 연달아 맡기기 | 농부가 바쁘면 **친구(하늘·바다·봄이)가 옷 색을 달리하고 도우러 와서** 함께 일하고, 끝나면 돌아감 (일손 최대 4명) |
| 목마른 작물에 물주기 | 드론이 가까운 칸부터 날아다니며 뿌림 |
| 물 많이 먹는 작물에 물주기 | 칸마다 스프링클러가 솟아 빙글빙글 |
| 논 전체 물대기 | 왼쪽 수로에서 물이 흘러 들어옴 |

연출은 보여 주기만 맡고, 실제 규칙(`farm/care.js`, `farm/harvest.js`)은 연출이 **그 칸에 닿는 순간** 실행돼요. 누가 가는 중인 칸은 같은 일을 두 번 맡기지 않도록 버튼이 잠시 숨겨져요. 그래서 흙이 젖는 순간과 그림이 맞아요. 시간을 숫자로 받아서, 테스트에서는 시간을 마음대로 앞으로 돌려 확인합니다.

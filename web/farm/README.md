# web/farm/ — 농사의 규칙

## 이 폴더는 왜 있나요? (기획안 3, 6절)
꾸미기만 하는 게임이 아니라 **진짜 농사를 짓는 느낌**을 주는 곳입니다. 작물마다 다른 성질을 가지고, 플레이어는 상태를 살펴 필요한 일을 골라야 해요.

## 담당 기능
### 1. 작물과 성장
- 재배 대상 14가지: **밭작물**(토마토·감자·당근·딸기·양배추·옥수수·호박), **논작물**(벼·흑미·연꽃), **꽃**(튤립·해바라기·코스모스·라벤더)
- 작물마다 다른 값: 성장 시간, 좋아하는 수분 범위, 수확량, 색상 후보 → `data/crops.json`에서 읽음
- 성장 단계: 씨앗 → 새싹 → 자람 → 수확 가능
- **시들거나 죽지 않음** — 힐링 게임이라 다 자란 작물은 수확할 때까지 그대로 기다려 줌 (타이밍에 쫓기지 않게). 오래 비우면 친구들이 대신 수확
- 성장 시간은 **게임 시간** 기준 (현실 시간 × 배율, → `time/`)
- 수분이 범위를 벗어나면 성장이 느려짐 (멈추거나 시들지는 않음)

### 2. 농사 관리
- **일괄 관리**: "물을 많이 먹는 작물에게만 물주기", "논 전체 물대기"처럼 작물 특징별로 한 번에 관리
- 상태 살피기: 목마름 / 다 자람 / 벌레 같은 표시를 보고 작업 선택
- 직접 관리와 자동화의 균형: 자동화(`smartfarm/`)는 연료가 필요해서 모든 걸 맡기기보다는 직접 돌보는 재미가 남도록 함

### 3. 돌연변이와 도감 (✔ 6단계, 일지 탭 `J`)
- 수확 시 낮은 확률(3%, `data/mutations.json`)로 돌연변이 — 색(무지개·반짝·파스텔), 모양(하트·별), 크기(큰·작은)
- 무작위는 농장 씨앗·칸·심은 시각으로 정해요 → 새로고침으로 다시 뽑을 수 없고, 테스트로 재현 가능 (날씨와 같은 "늘 같은 무작위")
- **라벨링 체험**: 처음 본 돌연변이에 특징 이름표를 달고 이름을 붙여 도감에 등록. 게임이 아는 정답과 비교해 부드럽게 알려 줌 (틀려도 벌칙 없음)
- 도감은 `meta.codex` (지문 서명 범위 안). 돌연변이 작물은 창고에 `mutant_작물_특징` 으로 들어가요

### 4. 성장과 해금 (✔ 6단계)
- **직접 플레이한 시간**(`meta.playSeconds`, 멍때리기·오프라인 제외)과 수확 수 같은 **서명된 숫자**가 쌓이면 새 것이 열림
- 작물 14가지는 처음부터 열려 있어요. 해금되는 것은 희귀 색(초콜릿 코스모스, 파란 튤립, 푸른 연꽃, 보라 옥수수)과 레시피(딸기 타르트, 호박 파이). 열린 것은 `meta.unlocked`
- 해금 조건은 `data/unlocks.json`에 표로 정리

### 5. 메뚜기 떼 (무결성 페널티)
- ✔ `server/integrity/`가 변조를 알리면 메뚜기 떼가 농장 전체를 휩쓰는 연출 실행 (`web/ui/critters.js` 의 `drawLocusts`, `web/main.js` 의 `tamperFlow`)
- 연출이 끝나면 본 농장을 **새 게임 상태로 완전 초기화** (도감 포함, 연구소 제외)
- 파일 손상은 변조가 아니므로 이 이벤트가 일어나지 않음 (구분 기준은 [integrity README](../../server/integrity/README.md))

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 순수 함수 `grow(crop, from, to)` | 같은 입력이면 같은 결과 → 플레이 중·오프라인 계산·테스트에서 똑같이 사용 |
| 시드 있는 난수 생성기 | 돌연변이 같은 무작위도 "다시 재현"할 수 있어 버그를 찾기 쉬움 |
| 데이터 주도 설계 | 작물을 추가할 때 코드가 아니라 `data/` JSON만 고치면 됨 |

## 파일
| 파일 | 하는 일 | 상태 |
|---|---|---|
| `crops.js` | 성장 계산(1분 조각), 수분 범위, 단계 | ✔ |
| `care.js` | 물주기, 논 물대기, 일괄 관리 | ✔ |
| `harvest.js` | 심기(색 고르기 포함), 수확 (돌연변이 판정은 6단계) | ✔ |
| `weather.js` | 날씨: 날짜·농장 씨앗으로 정해지는 맑음/비/눈/무지개, 비가 오는지 | ✔ |
| `tools.js` | 도구 규칙: 도구별 할 일, 알맞은 일, 칸 종류별 씨앗 기억, 씨앗·색 넘기기 | ✔ |
| `seed-gift.js` | 새 작물 씨앗 선물: 게임에 작물이 늘면 전부터 키우던 농장에도 씨앗을 한 번 (`meta.knownSpecies` 로 기억) | ✔ |
| `autopilot.js` | 멍때리기 모드: 다음 할 일 고르기 (수확 → 물주기 → 무작위 작물·색으로 심기) | ✔ |
| `codex.js` | 돌연변이 판정(늘 같은 무작위), 도감 등록, 라벨 비교·정확도 | ✔ |
| `unlocks.js` | 서명된 숫자로 해금 진행·판단, 열린 색·레시피를 게임 데이터에 더하기 | ✔ |

### 지금 적용된 규칙 숫자
- 흙이 마르는 속도: 밭·화단 0.4, 논 0.25 (게임 1분마다)
- 물주기 +40, 논 물대기 100으로
- 수분이 좋아하는 범위 밖이면 성장 속도 40%
- 다 자란 작물은 수확할 때까지 그대로
- 비가 오면 흙의 수분이 1분마다 1씩 그 작물이 좋아하는 범위의 가운데로 (마른 흙은 촉촉하게, 젖은 흙은 알맞게)

### 날씨 (힐링 원칙: 날씨는 돕기만 해요)
- 계절마다 비 오는 날의 확률: 봄 35%, 여름 40%, 가을 25%, 겨울 30%(눈)
- 비는 06:00~14:00 사이에 시작해 2~6시간, 그치면 1시간 반 동안 무지개 (해 지기 전까지)
- **같은 날은 언제 계산해도 같은 날씨** — 날짜와 농장 씨앗(만든 시각)으로 "늘 같은 무작위" 수를 만들어 정해요. 그래서 플레이 중이든 비운 시간을 나중에 계산하든 똑같이 비가 와요

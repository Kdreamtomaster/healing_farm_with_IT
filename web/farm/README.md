# web/farm/ — 농사의 규칙

## 이 폴더는 왜 있나요? (기획안 3, 6절)
꾸미기만 하는 게임이 아니라 **진짜 농사를 짓는 느낌**을 주는 곳입니다. 작물마다 다른 성질을 가지고, 플레이어는 상태를 살펴 필요한 일을 골라야 해요.

## 담당 기능
### 1. 작물과 성장
- 재배 대상: **밭작물**(토마토, 감자…), **논작물**(벼…), **꽃**(튤립, 해바라기…)
- 작물마다 다른 값: 성장 시간, 좋아하는 수분 범위, 수확량, 색상 후보 → `data/crops.json`에서 읽음
- 성장 단계: 씨앗 → 새싹 → 자람 → 수확 가능 (→ 너무 오래 두면 시듦. 오프라인 동안에는 친구들이 대신 수확)
- 성장 시간은 **게임 시간** 기준 (현실 시간 × 배율, → `time/`)
- 수분이 범위를 벗어나면 성장이 느려짐 (죽지는 않게 하여 힐링 분위기 유지)

### 2. 농사 관리
- **일괄 관리**: "물을 많이 먹는 작물에게만 물주기", "논 전체 물대기"처럼 작물 특징별로 한 번에 관리
- 상태 살피기: 목마름 / 다 자람 / 벌레 같은 표시를 보고 작업 선택
- 직접 관리와 자동화의 균형: 자동화(`smartfarm/`)는 연료가 필요해서 모든 걸 맡기기보다는 직접 돌보는 재미가 남도록 함

### 3. 돌연변이와 신품종
- 수확 시 아주 낮은 확률(예: 1% 미만)로 돌연변이 발생 — 색, 모양, 크기가 다름
- 발견한 돌연변이에 이름을 붙여 **도감에 신품종 등록** → 그 씨앗을 다시 심을 수 있음

### 4. 성장과 해금
- **직접 플레이한 시간**(오프라인 시간 제외)과 수확 횟수가 쌓이면 새 작물이 열림
- 해금 조건은 `data/unlocks.json`에 표로 정리

### 5. 메뚜기 떼 (무결성 페널티)
- `server/integrity/`가 변조를 알리면 메뚜기 떼가 농장 전체를 휩쓰는 연출 실행
- 연출이 끝나면 본 농장을 **새 게임 상태로 완전 초기화** (도감 포함, 연구소 제외)
- 파일 손상은 변조가 아니므로 이 이벤트가 일어나지 않음 (구분 기준은 [integrity README](../../server/integrity/README.md))

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 순수 함수 `grow(crop, from, to)` | 같은 입력이면 같은 결과 → 플레이 중·오프라인 계산·테스트에서 똑같이 사용 |
| 시드 있는 난수 생성기 | 돌연변이 같은 무작위도 "다시 재현"할 수 있어 버그를 찾기 쉬움 |
| 데이터 주도 설계 | 작물을 추가할 때 코드가 아니라 `data/` JSON만 고치면 됨 |

## 들어올 파일 (예정)
- `crops.js` — 성장 계산
- `care.js` — 물주기, 일괄 관리
- `harvest.js` — 수확, 돌연변이 판정
- `codex.js` — 도감 등록, 해금 확인
- `pests.js` — 메뚜기 떼 이벤트

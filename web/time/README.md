# web/time/ — 자동 저장과 방치형 시간

## 이 폴더는 왜 있나요? (기획안 4절)
게임을 꺼 둔 동안에도 농장의 시간은 흐릅니다. 다시 접속하면 **얼마나 지났는지 계산**해서 그동안의 변화를 한 번에 처리하고, 친구들이 무엇을 해 줬는지 알려 줘요.

## 시각을 기록하는 시점
| 시점 | 방법 | 의도 |
|---|---|---|
| 플레이 중 5분마다 | `setInterval` 자동 저장 | 갑자기 꺼져도 최대 5분만 잃음 |
| 게임 종료 시 | `pagehide` / `visibilitychange` + `navigator.sendBeacon` | 창을 닫는 순간에도 저장 요청이 전달되도록 |
| 게임 실행 시 | 서버가 시작할 때 실행 시각 기록 | 종료 저장이 실패했더라도 "언제 다시 켰는지"는 남김 |

## 오프라인 계산 흐름
```
접속 → 서버에서 (마지막 저장 시각, 지금 시각) 받기
     → 경과 시간 = 지금 - 마지막 저장
     → 안전 장치 적용
         · 음수(시계를 뒤로 돌림)면 0으로 처리하고 기록만 남김
         · 최대 처리 시간(예: 7일) 넘으면 잘라냄
     → 경과 시간을 작은 조각(예: 10분)으로 나눠 반복 시뮬레이션
         · 조각마다: 작물 성장 → 친구들이 목마른 작물에 물주기 → 기록
     → 로딩 화면에 결과 요약 멘트
         "5시간 12분 동안 농장을 비웠어요. 하늘이가 물을 3번 줬고, 토마토 4개가 다 자랐어요!"
```

## 농부의 친구들의 관리
- 오프라인 동안 **물주기와 기본 관리**를 담당해 작물이 무사히 자라게 도움
- 친구가 한 일은 `task_log`에 "친구 이름"으로 기록 → 로딩 멘트의 재료
- 수확·선물 만들기 같은 **즐거운 일은 플레이어 몫**으로 남겨 둠 (범위는 [PLAN 열린 질문 3](../../docs/PLAN.md))

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 고정 크기 시간 조각(tick) 시뮬레이션 | "10시간을 한 번에" 계산하면 중간에 물이 마르는 순간을 놓침. 조각으로 나눠 실제처럼 처리 |
| 플레이 중과 같은 규칙 함수 재사용 | `farm/`의 순수 함수에 `now`만 바꿔 넣으므로 온라인/오프라인 결과가 같음 |
| 서버 시각 기준 | 시계를 한 곳(로컬 PC)에서만 읽어 기준이 흔들리지 않게 함 |

## 들어올 파일 (예정)
- `autosave.js` — 5분 자동 저장, 종료 시 저장
- `offline.js` — 경과 시간 계산과 조각 시뮬레이션
- `helpers.js` — 친구들의 오프라인 관리 규칙
- `summary.js` — 로딩 화면 안내 멘트 만들기

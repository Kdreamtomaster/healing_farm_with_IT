# web/time/ — 자동 저장과 방치형 시간

## 이 폴더는 왜 있나요? (기획안 4절)
게임을 꺼 둔 동안에도 농장의 시간은 흐릅니다. 다시 접속하면 **얼마나 지났는지 계산**해서 그동안의 변화를 한 번에 처리하고, 친구들이 무엇을 해 줬는지 알려 줘요.

## 게임 시계와 배율
- 게임 속에는 **현실과 별개인 날짜**("3일째 07:30")가 있고, 계절은 이 날짜를 따릅니다 (→ `decor/`, 4단계)
- 게임 시간 = 현실 경과 시간 × **배율**. 화면 오른쪽 "설정"에서 ×1 / ×10 / ×30 / ×60 중 고름 (기본 ×30)
- 작물 성장도 게임 시간 기준으로 계산 → 배율을 올리면 작물도 빨리 자람
- 현재 게임 시간(`gameMinutes`)과 배율(`timeScale`)은 `meta` 표에 저장

## 저장하는 시점
| 시점 | 방법 | 의도 |
|---|---|---|
| 플레이 중 5분마다 | `setInterval` 자동 저장 | 갑자기 꺼져도 최대 5분만 잃음 |
| 탭을 숨기거나 창을 닫을 때 | `pagehide` / `visibilitychange` + `fetch(…, { keepalive: true })` | 창을 닫는 순간에도 저장 요청이 끝까지 전달되도록. 둘 중 먼저 온 쪽에서 한 번만 저장 |
| 게임 실행 시 | 서버가 실행 시각 기록 + 접속 직후 비운 시간을 처리하고 저장 | 종료 저장이 실패했더라도 "언제 다시 켰는지"는 남김 |
| 저장 버튼 | 직접 저장 | 원할 때 바로 |

## 비운 시간으로 보는 경우
| 경우 | 처리 |
|---|---|
| 게임을 껐다가 다시 켬 | 마지막 저장 시각 ~ 지금 |
| 탭을 숨김 (다른 탭, 창 최소화) | 숨긴 동안은 시계를 멈추고, 돌아오면 그 시간을 한 번에 처리 |
| 화면은 켜져 있는데 2분 넘게 시간이 건너뜀 (컴퓨터 잠자기 등) | 건너뛴 시간을 한 번에 처리 |

창을 켜 둔 채 자리를 비워도 친구들이 돌봐 주도록, "화면을 보고 있지 않은 시간"은 모두 비운 시간으로 처리합니다. 1분 넘게 비웠을 때만 안내 화면을 띄워요.

## 비운 시간 계산 흐름
```
현실 경과 시간 = 지금 - 기준 시각
  → 안전 장치
      · 음수(시계를 뒤로 돌림)면 0으로 처리하고 작업 기록에 남김
      · 현실 시간 기준 5일을 넘으면 5일로 잘라냄
  → 게임 경과 시간 = 현실 경과 시간 × 배율
  → 게임 시간 10분 조각으로 나눠 반복
      · 조각마다: 작물 성장(비가 오면 흙이 촉촉해져요) → 친구들이 수확·물주기
  → 결과 저장 → 로딩 화면에 안내
      "6시간 동안 농장을 비웠어요."
      "하늘이가 물을 3번 주고 토마토 3개를 수확해 창고에 넣어 뒀어요."
      (5일을 넘긴 경우) "너무 오래 비워서 친구들은 최근 5일 동안의 일만 기억하고 있대요."
```
처리가 길어질 수 있어(배율이 크면 수십만 분) 게임 하루치씩 나눠 계산하며 진행 막대를 그립니다.

## 농부의 친구들의 관리
- 친구마다 맡은 구획이 있음 (`data/friends.json`): 하늘 → 밭, 바다 → 논, 봄이 → 화단
- 10분마다 맡은 구획을 돌며 **다 자란 작물은 수확**해 창고에, **목마른 작물에는 물**(논은 물대기)
- 수확한 칸은 비워 둠 → 다시 심기, 선물 만들기와 나눔은 플레이어 몫
- 친구가 한 일은 친구별로 묶어 `task_log`에 기록 (물 한 번마다 적으면 너무 많아져서)
- 돌연변이 도감 등록은 6단계에서 추가

## 어떤 기술을 쓰나요?
| 기술 | 의도 |
|---|---|
| 고정 크기 시간 조각 시뮬레이션 | "10시간을 한 번에" 계산하면 중간에 물이 마르는 순간을 놓침. 조각으로 나눠 실제처럼 처리 |
| 플레이 중과 같은 규칙 함수 재사용 | `farm/`의 함수에 시간만 넣으므로 온라인/오프라인 결과가 같음 |
| 서버 시각 기준 | 접속 시에는 서버가 알려 준 시각으로 계산해 기준을 하나로 |
| `fetch` keepalive | 창이 닫혀도 저장 요청이 전달되도록 |

## 파일
| 파일 | 하는 일 |
|---|---|
| `clock.js` | 게임 시간 표시, 배율 목록, 현실 시간 ↔ 게임 시간 변환 |
| `offline.js` | 비운 시간 계획(5일 제한, 시계 역행), 10분 조각 시뮬레이션 |
| `helpers.js` | 친구들의 수확·물주기 규칙 |
| `summary.js` | 로딩 화면 안내 문장, 작업 기록 묶기 |
| `autosave.js` | 5분 자동 저장, 떠날 때 저장 |

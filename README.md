# 🌱 힐링 농장 with IT (healing_farm_with_IT)

> 작물을 기르고, 친구와 나누고, 코드와 지식도 함께 나누는 **도트 그래픽 힐링 농사 게임**

이 프로젝트는 두 가지 얼굴을 가지고 있어요.

1. **게임** — 밭과 논에서 작물과 꽃을 기르고, 색으로 농장을 꾸미고, 수확물로 선물을 만들어 농부의 친구들에게 나눠주는 방치형 농사 게임입니다. 게임을 쉬는 동안에는 친구들이 대신 농장을 돌봐 줍니다.
2. **배움터** — 게임 코드를 따라가다 보면 데이터베이스, 시간 처리, 자동화(DAG), 데이터 복구, 해시와 보안 같은 컴퓨터 과학의 기초를 자연스럽게 만나게 됩니다. 초등학생도 읽을 수 있도록 폴더마다 친절한 README가 있습니다.

> 🚧 현재 단계: **4단계 완료** — 농사, 저장, 방치형 진행, 색과 계절로 꾸미기, 도트 감성 소리까지 동작해요. 선물, 도감, 연구소 등은 아직 만드는 중입니다. 진행 계획은 [docs/PLAN.md](docs/PLAN.md)를 보세요.

## 무엇을 하는 게임인가요?

- **농사짓기** — 밭작물, 논작물, 꽃을 심고 물을 주고 수확합니다. 작물마다 좋아하는 물의 양과 자라는 속도가 달라요.
- **꾸미기** — 구획마다 색 조합을 정하고, 꽃과 작물의 색으로 나만의 농장 무늬를 만듭니다.
- **방치형 진행** — 게임을 끄고 있어도 시간은 흐릅니다. 다시 접속하면 "3시간 동안 친구들이 물을 줬어요!" 같은 안내와 함께 농장이 자라 있어요.
- **나눔** — 수확물로 꽃다발, 화분, 음식 같은 선물을 만들어 친구에게 줍니다. 많이 나눌수록 더 멋진 선물이 나올 확률이 올라가요.
- **발견** — 직접 농사지은 시간이 쌓이면 새로운 작물이 열리고, 아주 드물게 나타나는 돌연변이를 신품종으로 도감에 등록할 수 있어요.
- **스마트팜** — 농사 작업을 "씨앗 심기 → 수분 확인 → 물주기 → …" 같은 작업 흐름(DAG)으로 만들어 자동화합니다.
- **연구소** — 저장 데이터를 일부러 바꿔 보며 해시 검증이 어떻게 변조를 알아채는지 안전하게 실험하는 샌드박스 공간입니다.

## 어떻게 만들어지나요? (기술 방향)

```
[Chrome 브라우저]  ──요청──▶  [로컬 서버 (Python)]  ──▶  [SQLite 파일 saves/farm.sqlite]
  web/ : 화면 + 게임 규칙         server/ : 화면 파일 전달,            저장·백업·해시 검증
                                  저장/불러오기 창구
```

- **화면과 게임 규칙**은 브라우저에서 동작하는 HTML · CSS · JavaScript로 만듭니다. 빌드 도구 없이 파일을 열어 바로 고칠 수 있게 하는 것이 목표예요.
- **저장**은 Python 표준 라이브러리(`http.server`, `sqlite3`)로 만든 아주 작은 로컬 서버가 맡습니다. 별도 설치 없이 Python만 있으면 실행되도록 합니다.
- 서버는 내 PC 안(`127.0.0.1`)에서만 접속을 받습니다. 인터넷에 열리지 않아요.

자세한 선택 이유는 [docs/PLAN.md](docs/PLAN.md)의 "기술 결정" 절에 있습니다.

## 실행 방법

필요한 것: **Python 3.10 이상**, Chrome 브라우저 (추가로 설치할 패키지는 없어요)

```bash
git clone <이 저장소 주소>
cd healing_farm_with_IT
python server/main.py        # 실행하면 Chrome에서 게임 화면이 열립니다
```

- 브라우저가 열리지 않으면 터미널에 보이는 주소(`http://127.0.0.1:8765/`)를 Chrome에 직접 입력하세요.
- 끝낼 때는 터미널에서 `Ctrl+C`를 누르세요.
- 5분마다, 그리고 탭을 숨기거나 창을 닫을 때 자동으로 저장돼요.

### 지금 할 수 있는 것
1. 농장의 칸을 눌러 씨앗 심기 — 밭(토마토·감자), 논(벼), 화단(튤립)
2. 심기·물주기·수확 — 농부가 걸어가서 직접 (빠르게 연달아 맡기면 친구들이 도우러 와요) / 일괄 관리 — 드론(목마른 작물), 스프링클러(물 많이 먹는 작물), 물길(논 전체)
3. 다 자라면 수확 → 수확물과 씨앗이 창고로
4. 게임을 쉬는 동안(최대 5일) 친구들이 물을 주고 수확해 둠 → 다시 오면 안내 화면으로 알려 줌
5. 꾸미기: 칸마다 테두리 색 고르기, 작물 색 골라 심기(미리보기), 계절마다 바뀌는 풍경
6. 농장 풍경: 풀밭·나무·헛간, 수확할수록 쌓이는 작물 상자와 씨앗 자루
7. PC(16:9)와 휴대폰 세로·가로 화면(갤럭시 S25 등)에 맞춰 배치가 바뀌어요
8. 🍃 멍때리기 모드: 농부들이 알아서 수확하고, 물 주고, 무작위 작물·색으로 심어요. 메뉴는 숨고 농장만 크게
9. 설정에서 시간 배율(×1 / ×10 / ×30 / ×60), 효과음·배경음, 음량 바꾸기

기본 배율 ×30에서는 현실 1분이 게임 30분이에요. 튤립은 현실 약 4분, 벼는 약 12분이면 다 자랍니다.

### 테스트

```bash
python -m unittest discover -s tests/server -t tests/server   # 서버 테스트
```
게임 규칙 테스트는 서버를 켠 뒤 `http://127.0.0.1:8765/tests/web/` 를 열면 됩니다.
